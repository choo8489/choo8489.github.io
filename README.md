# 이동주 — 이력서 / 포트폴리오

Unity · XR · AI / 로봇 소프트웨어 엔지니어의 개인 이력서 사이트입니다.

**https://choo8489.github.io/**

## 구성

`index.html` 한 파일로 동작하는 정적 사이트입니다. 프레임워크·빌드 도구·외부 라이브러리를 쓰지 않았고,
CSS·JavaScript·SVG를 모두 문서 안에 인라인으로 넣었습니다.

```
index.html    사이트 본체
assets/       이미지/GIF 10개
robots.txt
```

- 다크/라이트 테마 전환 (선호 설정 감지 + 수동 토글, localStorage 저장)
- 기술 연혁 타임라인 — 데스크톱 가로 / 모바일 세로. 원형 메달리온은 사진 4장 + 인라인 SVG 도식 3장을 흑백으로 통일
- 프로젝트 카드 → 상세 모달 (키보드 조작·포커스 트랩, `#p-<id>` 딥링크 및 뒤로가기 지원)
- 프로젝트 목록은 `end`(종료월) 기준으로 런타임 정렬되므로 항목을 추가해도 최신순이 유지됩니다
- 개인 R&D / Private Labs 섹션 — private 저장소 중심의 개인 프로젝트를 GIF·도식·결과 중심으로 요약
- JavaScript 비활성 시 프로젝트 목록 텍스트 폴백(`<noscript>`)
- 인쇄 전용 스타일시트
- 반응형 레이아웃

## 이미지 출처

| 종류 | 설명 |
|---|---|
| 영상 썸네일 | 각 사 공식 YouTube 채널에 공개된 영상 (프로젝트 카드 + 기술 연혁 메달리온) |
| 알고리즘 결과 | `assets/gauge-detect.jpg` — 게이지 검출 알고리즘의 출력. 계기 주변만 남기고 잘라낸 뒤 비네팅으로 배경을 눌러 현장·위치 단서를 제거함 (게이지 카드 · 모달 · 기술 연혁 메달리온에 공용) |
| 멀티 QR 검출 결과 | `assets/multi-qrcode-detect.gif` — 테스트 영상에서 QR 테스트지 내부만 16:9로 크롭한 공개용 GIF. 송장·라벨 등 대외비 영역은 제외함 |
| 개인 R&D 미디어 | `assets/lab-fleet-viewer3d.gif`, `assets/lab-robopolishsim.gif`, `assets/lab-lcc-3dgs.gif`, `assets/lab-sensus-oct.png` — private repo 내용을 설명하기 위한 합성 데모 GIF와 센서 시뮬레이션 결과 이미지 |
| 개념 도식 | `index.html`의 `DIAGRAM` 객체와 기술 연혁 섹션에 직접 작성한 인라인 SVG |
| 추상 배경 | 이미지 생성 모델로 만든 장식용 이미지 (해당 카드에 표기) |
| 공개 참조 링크 | Narang 등 실제 서비스 화면의 권리 범위가 불명확한 프로젝트는 이미지 재사용 대신 기사·앱 소개 페이지 링크만 연결 |

기술 연혁 메달리온은 16:9 썸네일을 1:1 원형으로 자르므로, 프레임마다
`--ox`(가로 위치) · `--z`/`--zx`/`--zy`(확대 중심)를 인라인 스타일로 지정해 피사체를 맞춥니다.

프로젝트 화면·현장 사진 등 회사 및 고객사 자산은 포함하지 않았습니다.
Narang 앱 스크린샷처럼 공개 페이지에 남아 있더라도 초상권·저작권·계약 범위를 확인하기 어려운 이미지는 직접 복사하지 않고 참조 링크로만 안내합니다.
공개된 자료가 없는 과제는 개념 도식으로 대체하고, 상세 화면에 비공개 사유를 표기했습니다.

## 로컬 실행

별도 빌드가 필요 없습니다. `index.html`을 브라우저로 열면 됩니다.
