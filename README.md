# 이동주 — 이력서 / 포트폴리오

Unity · XR · AI / 로봇 소프트웨어 엔지니어의 개인 이력서 사이트입니다.

**https://choo8489.github.io/**

## 구성

`index.html` 한 파일로 동작하는 정적 사이트입니다. 프레임워크·빌드 도구·외부 라이브러리를 쓰지 않았고,
CSS·JavaScript·SVG를 모두 문서 안에 인라인으로 넣었습니다.

```
index.html    사이트 본체
assets/       이미지 4장
robots.txt
```

- 다크/라이트 테마 전환 (선호 설정 감지 + 수동 토글, localStorage 저장)
- 프로젝트 카드 → 상세 모달 (키보드 조작·포커스 트랩 지원)
- 인쇄 전용 스타일시트
- 반응형 레이아웃

## 이미지 출처

| 종류 | 설명 |
|---|---|
| 영상 썸네일 | 각 사 공식 YouTube 채널에 공개된 영상 |
| 개념 도식 | `index.html`의 `DIAGRAM` 객체에 직접 작성한 인라인 SVG |
| 추상 배경 | 이미지 생성 모델로 만든 장식용 이미지 (해당 카드에 표기) |

프로젝트 화면·현장 사진 등 회사 및 고객사 자산은 포함하지 않았습니다.
공개된 자료가 없는 과제는 개념 도식으로 대체하고, 상세 화면에 비공개 사유를 표기했습니다.

## 로컬 실행

별도 빌드가 필요 없습니다. `index.html`을 브라우저로 열면 됩니다.
